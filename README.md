# 네트워크관리사 2급 학습실

모바일 브라우저에서 통학 중 짧게 학습하도록 만든 정적 웹앱 MVP입니다.

## 실행

- `index.html`을 브라우저에서 열면 동작합니다.
- GitHub Pages를 활성화하면 저장소 웹 주소에서 사용할 수 있습니다. 저장소 Settings → Pages에서 배포 소스를 설정하세요.
- 서버·계정 없이 동작하며 학습 기록은 현재 브라우저의 `localStorage`에 저장됩니다.

## 기능

- 이론 / 필기 / 실기 영역별 객관식 연습
- 자동 채점 및 문항별 해설
- 오답 노트, 오답 재풀이, 북마크
- 풀이 수, 누적 정답률, 영역별 진도·학습률 분석
- JSON 기록 내보내기 및 백업 가져오기
- 로컬 기록 초기화

## 데이터 관련 안내

현재 `index.html`에는 동작 확인용으로 자체 작성한 예시 문항 9개가 포함되어 있습니다. 원본 `sumilee-phd/NA2-study`는 별도 React 앱이며, README에 따르면 필기 900문항 및 검수된 실기 문항 등 독자적인 데이터·구현을 포함합니다. 원본의 전체 문제·해설·데이터를 그대로 복제하지 않았습니다. 전체 문제은행을 추가하려면 각 자료의 라이선스와 재사용 허가를 확인하고, 사용 권한이 있는 JSON 데이터를 추가해야 합니다.

## 저장 방식의 한계

- 기록은 브라우저·기기별로 분리되며 서버 동기화는 없습니다.
- 브라우저 저장소를 삭제하면 기록이 사라질 수 있으므로 정기적으로 JSON 백업을 권장합니다.
- 이 앱의 학습률은 포함된 문항 중 한 번 이상 정답 처리한 문항의 비율입니다. 실제 자격시험 합격 가능성을 의미하지 않습니다.
